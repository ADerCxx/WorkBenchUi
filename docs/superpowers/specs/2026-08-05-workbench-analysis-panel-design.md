# 工作台 — 分析工具浮窗壳

日期：2026-08-05  
状态：已实现  

参照：`src/工作台分析工具.md`

## 目标

在知识织物工作台顶栏右上角提供「分析工具」入口：打开可拖拽、可缩放的浮窗，承载后续「一键分析 → 流式总结 + 关系图谱」的结果区。本轮只交付**入口 + 浮窗壳 + 交互态**，不接分析接口与图谱实现。

### 成功标准

1. 未选中文件时，顶栏「分析工具」按钮禁用；已选中文件时可点击打开浮窗
2. 浮窗支持：一键分析（占位提示）、最小化（右下角胶囊还原）、全屏（占满视口并提供返回）、关闭（重置）
3. 普通态支持拖拽与边角缩放；尺寸过小（宽 &lt; 480 或高 &lt; 320）时内容区提示拉大
4. 浮窗内左右两栏占位（左「AI 分析结果」、右「关系图谱」），无真实数据
5. 一键分析仅 `message.info` 占位，不发起网络请求
6. 关闭后再打开为默认位置与尺寸；不持久化窗口态

## 非目标

- 后端分析接口、流式输出、关系图谱渲染
- 分析结果记忆 / 打开时按情况回填（后续独立设计，经接口服务实现）
- 多文件选中与批量分析
- 从 ForgeKit 搬迁 parse / graph / AI 关系分析
- 改动扫描、白名单、正则设置等既有能力

## 背景

工作台已具备：选项目根 → 白名单扫描 → 左树选文件 → 右原文预览。顶栏目前仅有「选择文件夹」。分析工具是工作台核心能力的下一切片：先把结果容器与窗口交互做稳，再接分析与图谱。

## 决策

采用 **自研浮动面板 + `react-rnd`（或等价库）**，不扩展 antd `Modal`。

| 决策点 | 选择 | 说明 |
|--------|------|------|
| 技术方案 | 浮层 + react-rnd | 拖拽/缩放/最小化/全屏贴合需求；Modal 语义不适配 |
| 本轮范围 | 仅壳 + 占位 | 左右栏与一键分析均不接真实能力 |
| 未选文件 | 禁用入口按钮 | 必须选中文件才能打开 |
| 一键分析 | message 占位 | 如「分析能力即将接入」 |
| 最小化形态 | 右下角胶囊 | 标题「分析工具」+ 点击还原 |
| 关闭后再开 | 完全重置 | 位置/尺寸/模式均回默认；记忆留给后续接口 |
| 选中变化 | 不自动关窗 | 切换文件常见；取消选中时浮窗可仍开着，顶栏按钮随 `selectedPath` 禁用 |
| 全屏 → 最小化 | 允许 | 还原到普通态（不自动回全屏） |
| 顶栏按钮顺序 | 选文件夹在左、分析工具在右 | 突出「对当前选中」的核心动作 |
| 遮罩 | 无 | 浮窗打开时可继续操作目录树/预览 |

## 技术方案

### 页内结构（增量）

```
pages/Workbench/
  index.tsx                 # 增：analysisOpen / analysisMode 编排
  components/
    WorkbenchHeader/        # 增：分析工具按钮（disabled 随 selectedPath）；样式见同级 index.less
    AnalysisPanel/          # 新建：浮窗壳
      index.tsx
      types.ts
      index.less
```

最小化胶囊可内联于 `AnalysisPanel`，或同目录小子组件；保持一模块一文件夹即可。

### 状态

| 状态 | 含义 |
|------|------|
| `closed` | 未挂载浮窗与胶囊 |
| `normal` | 可拖拽缩放的浮窗 |
| `minimized` | 浮窗隐藏，右下角胶囊可见 |
| `fullscreen` | 占满视口；不可拖拽缩放；提供退出全屏 |

转移：

- 顶栏打开：`closed` → `normal`
- 最小化：`normal` \| `fullscreen` → `minimized`（还原前尺寸记在组件内；从全屏最小化则还原为进入全屏前的普通尺寸）
- 胶囊还原：`minimized` → `normal`
- 全屏 / 退出全屏：`normal` ⇄ `fullscreen`
- 关闭：任意 → `closed`（清空尺寸与模式记忆）

编排建议放在 `Workbench`：`analysisMode` 为 `null` 表示 closed；非 `null` 时渲染 `AnalysisPanel`（含最小化态）。

### 交互细节

- **默认几何：** 视口内合理默认宽高（例如约 720×480），大致居中或偏中上
- **拖拽：** 普通态，标题栏为拖动手柄
- **缩放：** 普通态边角；低于阈值不强制改尺寸，仅内容提示
- **一键分析：** 标题栏按钮 → `message.info`；本轮不读 `selectedPath` 内容上传
- **z-index：** 高于工作台内容，不遮挡 antd `message`

### 依赖

- 新增：`react-rnd`（若选型调整，须仍满足拖拽 + 缩放，并在实现计划中写明）

### 错误与边界

- 尺寸过小：提示文案固定为「尺寸过小，呈现效果不佳，请拉大弹窗」
- 本功能不依赖 File System Access API；与选文件夹能力解耦
- 后续「打开时查找记忆」不在本设计范围，实现时勿在本轮预埋假接口

## 测试要点

1. 无选中：分析按钮 disabled；有选中：可开窗
2. 拖拽、缩放、过小提示可见
3. 最小化 ↔ 胶囊还原；全屏 ↔ 返回；关闭后再开为默认几何
4. 一键分析仅出现占位 message，Network 无分析请求
5. 浮窗打开时切换选中文件：窗不关；清空选中：窗可不关，按钮变 disabled
