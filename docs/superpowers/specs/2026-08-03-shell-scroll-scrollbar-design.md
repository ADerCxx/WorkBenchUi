# WorkBench 外壳锁视口与统一滚动条

日期：2026-08-03  
状态：已实现

## 目标

在外壳已全宽的基础上，补齐视口占满与滚动边界，并统一项目滚动条外观；主题主色单独由 ConfigProvider 控制。

### 成功标准

1. **外壳占满视口**：应用外壳在宽、高方向均占满可用屏幕（视口），无居中窄条或外壳被内容撑出视口外的滚动条。
2. **外壳不滚动**：`html` / `body` / 根挂载壳不出现页面级滚动。
3. **仅内部滚动**：滚动发生在 Layout 内容区及页面内的子滚动容器（如表格、弹层内容等），顶栏 / 侧栏等壳层结构保持固定在视口内。
4. **主题主色**：通过 Antd `ConfigProvider` 设定 `colorPrimary`，与现有全局 `--accent` 对齐（组件主色；与滚动条色解耦）。
5. **滚动条统一**：
   - 轨道透明（或视觉上不抢眼）
   - 细滑块、圆角
   - 滑块为常见灰黑色半透明（不宜过深），悬停时略加深；亮色用黑半透明，暗色用白半透明
   - 覆盖范围：全局可滚动区域，以及 Antd 常见内部滚动容器（如表体、Modal 内容、下拉面板等），避免系统默认滚动条与壳内滚动条混用

## 非目标

- 不改路由表与业务接口逻辑
- 不为各业务页单独规定内容 `max-width` / 排版（仍由页面自控）
- 不引入新的布局框架或整站主题体系搬迁
- 不在本需求中改写无关业务组件行为

## 产品决策

| 决策点 | 选择 |
|--------|------|
| 视口与滚动 | 外壳锁高锁宽，仅内容区及子容器滚动 |
| 主色来源 | `ConfigProvider.theme.token.colorPrimary = #aa3bff`（对齐 `--accent`） |
| 滚动条范围 | 全局可滚区域 + Antd 常见滚动容器一并统一 |
| 滚动条色 | 常见灰黑半透明（亮色 `rgba(0,0,0,.28)` / 悬停 `.42`；暗色白半透明同透明度），不跟主色 |

## 验收标准

1. 宽屏下外壳贴满视口；拉高内容时，浏览器窗口本身不出现整页滚动条，内容区出现内部滚动。
2. `MainLayout`、`WorkbenchLayout`、`BlankLayout` 下均满足「壳不滚、内容可滚」（Blank 若仅有占位内容，至少壳不溢出视口）。
3. Antd 主色按钮 / 开关等呈现 `#aa3bff` 系主色。
4. Layout 内容区与典型 Antd 滚动容器（如 Table 表体）滚动条形态一致：细、圆角、灰黑半透明滑块（不过深）。

## 与既有文档关系

本需求建立在「外壳全宽」已落地的前提下，补充**高度占满、滚动边界、主色与滚动条**；不回退全宽决策。
