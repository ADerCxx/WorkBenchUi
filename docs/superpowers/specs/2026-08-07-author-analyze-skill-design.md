# 元 Skill：按文档类型产出解析 Skill

日期：2026-08-07  
状态：已实现  

参照：`src/工作台内置解析Skill探索方法论.md`（实现时由元 Skill 吸收/替换；作者自有备份）

## 目标

在 WorkBench 落一份**元 Skill**（Cursor 显式点名使用）：按「文档类型」走完探索方法论，产出一份可带走的**解析 Skill**（标准 `SKILL.md` 包），用于约束 Agent 对该类文档做精辟、可扫读、突出重点的分析。

### 成功标准

1. 给定文档类型名，能按流程完成：找材料 → 抽共性/问题清单 → 探索摘要确认 → 落盘
2. 落盘路径为「目标项目根」下的 `<name>/SKILL.md`（目录名 = `name`）
3. 解析 Skill 的输出约束可追溯到「读者最想知道什么」，并要求文件关系分析与中文短句文风
4. 样本不足、同名冲突、未确认时不落盘（行为可复现）

## 非目标

- 工作台 UI 注入、一键分析、关系图谱
- 在业务项目内消费/注册这些解析 Skill（生成物用于带走到别处）
- 第一版支持非 Markdown 文档

## 背景

工作台需要多种「内置解析 Skill」，按文档专用约定 LLM 的分析行为。方法论文档已总结四步：文档从何而来 → 找生成约定 → 想读者要什么 → 总结成解析 Skill。现缺一份**可执行的元 Skill**，让 Agent 能按类型稳定产出解析 Skill，并补上样本不一致、确认门、落盘冲突等注意点。

## 决策

采用 **流水线元 Skill**（硬门禁流程），单文件 `SKILL.md`，不拆 `reference.md`。

| 决策点 | 选择 | 说明 |
|--------|------|------|
| 交付物 | 仅元 Skill | 方法论并入；不另留平行「人读手册」 |
| 调用方式 | Cursor 显式点名 | 第一版不接工作台注入 |
| 找材料 | 先自助再要样例 | 按类型名搜约定/样例；不足再请用户提供 |
| 同类不一致 | 共性 + 问题清单回退 | 稳定结构写约定表；否则只定读者问题 |
| 确认 | 两段式 | 先探索摘要，确认后再写盘 |
| 落盘 | 目标根 `/<name>/SKILL.md` | 默认目标根 = 当前工作区根；可指定其它项目根 |
| 覆盖 | 默认拒绝 | 除非用户明确要求覆盖 |
| 生成物 frontmatter | 仅 `name` + `description` | 不加其它 frontmatter 约束 |
| 输出骨架 | 少固定信息类型 | 不定死过多标题；以读者问题为纲 |

## 架构

```text
用户（文档类型名 [+ 目标根/name/样例]）
        │
        ▼
┌───────────────────┐
│ 元 Skill（WorkBench）│  流程 + 门禁 + 自检
└─────────┬─────────┘
          │ 确认后写盘
          ▼
  <目标项目根>/<name>/SKILL.md   ← 可带走的解析 Skill
```

- **元 Skill**：教 Agent 如何探索并编写解析 Skill；落在 `.cursor/skills/author-analyze-skill/SKILL.md`
- **解析 Skill**：懂某类文档约定的阅读助手手册；不默认绑定 WorkBench 目录结构

## 流程与门禁

1. **收输入**：文档类型名必填；目标根、`name`、样例/约定路径可选。`name` 默认 `analyze-<短横线类型>`。
2. **找材料**：在目标仓库搜生成约定与同类型样例。建议至少 2 份样例再写强约定；仅 1 份须用户声明「仅此一份」（或明确要求继续），约定表标弱/可选。找不到则停，请用户补路径或正文。
3. **抽规律**：多份对照抽共性；差异标可选/可能缺失；无稳定章节则进入问题清单模式。
4. **读者透镜**：列出读该类文档最想知道的问题（宜少）；作为解析 Skill 输出约束来源。
5. **探索结论摘要（确认门）**：含类型、`name`、路径、材料来源、模式、读者问题、少量共通信息类型、风险。**未确认不写盘。**
6. **生成并落盘**：完整 `SKILL.md` → `<目标根>/<name>/SKILL.md`；同名存在则拒绝覆盖。
7. **落盘前自检**：无编造；术语白话；输出约束来自读者问题；文件关系为必要要求。

### 错误与停手

| 情况 | 行为 |
|------|------|
| 无样例且用户未提供 | 停，说明缺失并请补 |
| 仅 1 份样例且未声明「仅此一份」/未要求继续 | 可给探索摘要，不落盘 |
| 同名 `SKILL.md` 已存在 | 拒绝覆盖，除非用户明确覆盖 |
| 目标根无效/不可写 | 报错，请指定可用根 |
| 摘要未确认 | 不落盘 |

## 生成物（解析 Skill）形态

标准 Cursor Skill 包：`<name>/SKILL.md`。

**frontmatter**：`name`、`description`（第三人称 + 触发场景）。

**正文建议块**（标题可微调）：

1. 角色（阅读助手；默认只读分析、不改文件）
2. 文档长什么样：约定速查 **或** 问题清单模式说明
3. 输入（信任调用方正文；截断要标明）
4. 分析步骤（短、按序）
5. 输出约束（读者问题为纲；少量共通信息类型即可，如身份、关联）
6. 文风（中文、短句、少术语、篇幅宜短；不确定写「正文未写明」；**文件关系必要**）

**禁止**：把偶然写法写成必须有；编造未出现的路径/依赖；用难懂术语堆分类名。

## 测试要点

- 有多份较一致样例：走共性约定模式，摘要确认后落盘成功
- 同类样例结构分歧大：进入问题清单模式，不写假章节表
- 仓库内找不到材料：停并提示补样例
- 同名已存在：拒绝覆盖；明确「覆盖」后可写
- 未确认摘要：工作区无新 `<name>/SKILL.md`
